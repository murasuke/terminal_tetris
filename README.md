# ターミナルで動くテトリス

## はじめに

ターミナルはセル単位に塗りつぶすのが簡単なので、テトリスなんて簡単にできるんじゃね？と思いつきで作ってみました

初テトリス？でしたが、必要な機能を考えてから作ればそれほど難しくはなかったです

Vim、Emacsユーザーには見慣れた光景だと思います

## テトリスを実装するために必要な要素

テトリスを実装するため、最低限必要な機能
1. セル単位(座標を指定して)に塗りつぶしができる
1. キーボード押下で即時にイベント処理が行える
1. タイマーで処理を行える
1. 文字や塗りつぶしを行う際、色を指定できる
1. 文字を出力できる

実際のところ、`セルの塗りつぶし` = `文字'██'の出力`ですので、実質4つの要素があれば実装できることになります
