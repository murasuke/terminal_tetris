# 3. 文字列で画面を操る――エスケープシーケンス

前章では、ターミナルの任意の座標へ、色のついた文字を出力する手法を紹介しました。この章では、その仕組みをNode.jsのコードへ落とし込み、テトリスの盤面を描くために必要となる関数を作ります。

ここで扱うのは、次の3つの操作です。

- カーソルを移動し、指定した座標へ文字を表示する
- 表示する文字に色を付ける
- 移動前のブロックや画面全体を消す

いずれも、Node.jsからエスケープシーケンスを出力し、ターミナルに解釈させることで実現します。

## 3.1 プログラムとターミナルの間で何が起きているのか

普段ターミナルでコマンドを実行するときは、「ターミナル」と「シェル」をまとめて一つのものとして意識しがちです。しかし、プログラムから画面を制御するときは、それぞれの役割を分けて考える必要があります。

| 要素 | 役割 |
| --- | --- |
| ターミナルエミュレーター | 文字を画面へ描画し、色やカーソル位置を制御する |
| シェル | コマンドを受け取り、指定されたプログラムを起動する |
| Node.jsプログラム | ゲームの状態を計算し、表示したい文字列を標準出力へ書き込む |

Windows Terminalはターミナルエミュレーター、Git Bashで動いているBashはシェル、今回作る `tetris.js` はNode.jsプログラムに当たります。

シェルから `node tetris.js` を実行すると、シェルがNode.jsプログラムを起動します。起動後、プログラムが標準出力へ書き込んだデータはターミナルエミュレーターへ渡されます。

```text
Node.jsプログラム
        │
        │ process.stdoutへの書き込み
        ▼
     標準出力
        │
        ▼
ターミナルエミュレーター
        │
        ▼
      画面表示
```

標準出力へ普通の文字列を書き込むと、ターミナルはその文字を現在のカーソル位置へ表示します。

```js
process.stdout.write('Hello');
```

一方、文字列に制御文字の `ESC` を含めると、ターミナルはその部分を画面制御の命令として解釈します。JavaScriptでは、`ESC` を16進数の文字コードを使って `\x1b` と記述します。

```js
process.stdout.write('\x1b[31mHello\x1b[0m');
```

このコードを実行しても、画面に `\x1b[31m` という文字がそのまま表示されるわけではありません。対応しているターミナルはこれを「これ以降の文字を赤色にする命令」として処理し、`Hello` だけを赤色で表示します。

このように、ターミナルの制御に使う文字列を**エスケープシーケンス**と呼びます。エスケープシーケンスのうち、今回よく使うものは次の形をしています。

```text
ESC [ パラメーター 命令文字
```

`ESC` に続く `[` までを合わせて、**CSI（Control Sequence Introducer）**と呼びます。JavaScriptでは `ESC [` を `\x1b[` と書き、その後ろに座標や色番号などのパラメーターと、処理を表す命令文字を続けます。

### `console.log()`ではなく`process.stdout.write()`を使う

Node.jsで文字を表示するときは、通常 `console.log()` を使います。しかし、`console.log()` は文字列の末尾に改行を追加します。描画するたびに改行されると、カーソル位置を細かく制御するゲームでは不便です。

`process.stdout.write()` は、渡した文字列を改行せず、そのまま標準出力へ書き込みます。エスケープシーケンスと描画する文字を一つの文字列にまとめて送信することもできます。

```js
const sequence = '\x1b[31m';
const chars = '██';

process.stdout.write(sequence + chars);
```

以降、画面の描画には `process.stdout.write()` を使用します。

## 3.2 カーソルを移動して、好きな座標に描く

ターミナル上の指定した位置へ文字を表示するには、まずカーソルをその位置へ移動します。カーソルの絶対位置を指定するCSIシーケンスは、次の形式です。

```text
ESC [ 行 ; 列 H
```

JavaScriptの文字列では、次のように記述します。

```js
'\x1b[3;5H'
```

この例では、カーソルを上から3行目、左から5列目へ移動します。最後の `H` がカーソル位置を指定する命令文字です。

注意したいのは、ターミナルでは縦位置である**行を先に**、横位置である**列を後に**指定する点です。プログラムでよく使う `(x, y)` の順番とは逆になります。

さらに、ターミナルの座標は左上を `(1, 1)` として数えます。一方、JavaScriptの配列添字は `0` から始まります。ゲーム内の座標をJavaScriptに合わせて0始まりにすると、描画時にはそれぞれ `1` を加える必要があります。

| 位置 | JavaScript上の座標 `(x, y)` | ターミナルへ渡す座標 `(行, 列)` |
| --- | --- | --- |
| 左上 | `(0, 0)` | `(1, 1)` |
| 右へ4、下へ2進んだ位置 | `(4, 2)` | `(3, 5)` |

この変換を毎回書かなくて済むように、座標と文字列を受け取る `draw()` 関数を作ります。

```js
/**
 * 任意の位置に文字を描画する
 * @param {number} x - 横位置（0始まり）
 * @param {number} y - 縦位置（0始まり）
 * @param {string} chars - 描画する文字列
 */
function draw(x, y, chars) {
  const row = y + 1;
  const column = x + 1;
  const sequence = `\x1b[${row};${column}H`;

  process.stdout.write(sequence + chars);
}
```

`draw()` の引数は `(x, y)` の順番ですが、エスケープシーケンスへ埋め込むときは `${row};${column}`、つまり `y`、`x` の順番になります。

次のように呼び出すと、三つのセルを階段状に表示できます。

```js
draw(0, 0, '██');
draw(2, 1, '██');
draw(4, 2, '██');
```

```text
██
  ██
    ██
```

ファイルへ保存してNode.jsで実行すると、改行を出力していないにもかかわらず、指定した座標に文字が配置されます。

```bash
node draw-position.js
```

これで、ターミナルを上から順に書き足すのではなく、必要な位置だけを書き換えられるようになりました。

## 3.3 文字に色を付ける

次に、描画する文字へ色を付けます。文字色や背景色、太字などの表示属性を指定する命令を**SGR（Select Graphic Rendition）**と呼びます。

SGRは、CSIに色番号などのパラメーターを続け、最後に `m` を付けた形式です。

```text
ESC [ 色番号 m
```

基本的な文字色には、次の番号が割り当てられています。

| 色番号 | 文字色 | 色番号 | 文字色 |
| --- | --- | --- | --- |
| `30` | 黒 | `34` | 青 |
| `31` | 赤 | `35` | マゼンタ |
| `32` | 緑 | `36` | シアン |
| `33` | 黄 | `37` | 白 |

たとえば、赤色を指定するエスケープシーケンスは `\x1b[31m` です。

色の指定は、リセットをするまでその後に出力する文字にも引き継がれます。指定したセルだけに色を付けるには、文字を出力した直後に `\x1b[0m` を送り、表示属性をリセットします。

```js
process.stdout.write('\x1b[31m赤色\x1b[0m');
process.stdout.write('通常の色');
```

リセットを忘れると、ゲームの外側にあるシェルのプロンプトまで同じ色で表示されることがあります。そこで、色の指定とリセットも `draw()` の中に組み込みます。

```js
/**
 * 任意の位置に、色を指定して文字を描画する
 * @param {number} x - 横位置（0始まり）
 * @param {number} y - 縦位置（0始まり）
 * @param {string} chars - 描画する文字列
 * @param {string|number} color - ANSIカラー番号
 */
function draw(x, y, chars, color = 37) {
  const moveCursor = `\x1b[${y + 1};${x + 1}H`;
  const setColor = `\x1b[${color}m`;
  const resetStyle = '\x1b[0m';

  process.stdout.write(moveCursor + setColor + chars + resetStyle);
}
```

これで、座標と文字に加えて色番号を指定できます。

```js
draw(0, 0, '██', 31); // 赤
draw(2, 1, '██', 34); // 青
draw(4, 2, '██', 32); // 緑
```

完成版では、テトリミノを表す配列の値 `1` から `7` を、色番号 `31` から `37` に対応させます。定数 `COLOR_OFFSET` を使うと、配列の値に `30` を足すことで色番号へ変換できます。

```js
const COLOR_OFFSET = 30;

const colorValue = 1; // 配列上の「赤いセル」
const ansiColor = COLOR_OFFSET + colorValue; // 31
```

これにより、二次元配列の1つの数値で「セルが埋まっているか」と「何色で描くか」の両方を表せます。

## 3.4 描いたものを消す

ブロックを移動させるには、新しい位置へ描くだけでなく、移動前の表示も消さなければなりません。ターミナルでは、表示した文字そのものを画面から取り除くのではなく、同じ位置へ空白を描いて上書きします。

### 空白で必要な部分だけを消す

今回のテトリスでは、1つのセルを `██` で描くため、消去するときは同じ幅の2つの空白を使います。

```js
draw(4, 2, '██', 31); // ブロックを描く
draw(4, 2, '  ');     // 同じ位置を空白で上書きする
```

ブロックを右へ動かす場合の処理は、次の順番になります。

1. 現在位置へ空白を描き、移動前のブロックを消す
2. ブロックの横位置 `x` を増やす
3. 新しい位置へブロックを描く

盤面の大部分を描き直さず、変化した部分だけを更新できることが、この方法の利点です。

### 画面全体を消去する

行を消した後など、盤面全体を描き直したい場合は、画面を消去するCSIシーケンスを使います。

```text
ESC [ 2 J
```

JavaScriptでは `\x1b[2J` と記述します。`J` は画面の消去、パラメーターの `2` は画面全体を対象にすることを表します。

画面を消去しても、カーソル位置は左上へ戻るとは限りません。そのため、カーソルを左上へ移動する `\x1b[H` も続けて出力しておくと、再描画を常に同じ位置から始められます。

```js
function resetScreen() {
  process.stdout.write('\x1b[2J\x1b[H');
}
```

画面全体の消去は分かりやすい反面、何度も実行するとターミナルによってはちらついて見えることがあります。普段の移動では空白による部分消去を使い、行消去など盤面が大きく変化するときだけ全体を描き直します。

### ゲームの1セルを`██`で表す

ターミナルの描画単位はピクセルではなく文字です。一般的なフォントでは、一文字分の表示領域は横より縦に長いため、`█` を一文字だけ表示すると、テトリスのセルも縦長に見えます。そこで、横に二文字並べた `██` をゲーム上の1セルとして扱い、正方形に近づけます。

このとき、ゲーム上の横座標とターミナル上の列番号は一致しません。ゲーム上で `x` が1増えるたびに、ターミナル上では2列進める必要があります。

```js
const CELL = '██';

function drawBlock(x, y, blockMatrix, chars = CELL) {
  blockMatrix.forEach((row, dy) => {
    row.forEach((value, dx) => {
      if (value !== 0) {
        const terminalX = (x + dx) * 2;
        const terminalY = y + dy;
        const color = 30 + value;

        draw(terminalX, terminalY, chars, color);
      }
    });
  });
}
```

`x` と `dx` はゲーム上のセル単位ですが、`draw()` へ渡す直前に `2` を掛け、ターミナル上の列へ変換しています。縦方向は一文字で1セルを表せるため、`y + dy` のままです。

文字の表示幅は、使用するフォントやターミナルの設定によって異なる場合があります。盤面がずれて見える場合は、等幅フォントを使用しているか、`█` が一文字分の幅で表示されているかを確認してください。

これで、任意の位置へ色付きのセルを描き、必要に応じて消せるようになりました。次章ではRawモードを使い、Enterキーを待たずに矢印キーなどの入力を受け取る方法を実装します。
