## 2. テトリスに必要な機能を分解する

ターミナルの機能を利用する、プログラム(node.js)側で行う処理を分けて説明します。

### 2.1 ターミナルに任せること
- 任意の座標に文字を表示する
- 文字に色を付ける
- 表示した文字を消す
- キー入力を即座に受け取る

#### 任意の座標に文字を表示する

指定した位置に文字を出力するには、`エスケープシーケンス`を利用します

- `エスケープシーケンス`とは

`Escキー`のキーコード(`\x1b`)でで始まる文字列を、`エスケープシーケンス`と呼びます

慣例的に、16進コード(`\x1b`)ではなく「`\e` または `\033`」 で書くことが多いです


- カーソルをn行、m桁目へ移動（左上を1,1にした絶対座標）
```
\033[n;mH
```

このエスケープシーケンスを echo で出力した後、出力したい文字列を echo すると指定した座標から文字列が出力されます

- 7行、5列目 空文字を出力するエスケープシーケンスの後ろに文字列「abc」を出力したサンプル
```

tkykn@DESKTOP-0IMGJGP MINGW64 ~
$ echo -e "\033[7;5Habc"
echo -e "\033[7;5Habc"


    abc
```
